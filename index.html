Tujuan Pembelajaran DPIB Kelas X

  • Mengidentifikasi karakteristik tumpuan Sendi, Rol, dan Jepit pada konstruksi nyata.
  • Menerapkan 3 syarat keseimbangan statika (ΣFx = 0, ΣFy = 0, ΣM = 0) untuk mencari reaksi.
  • Menganalisis dan membaca diagram gaya lintang (SFD) dan diagram momen (BMD) gelagar sederhana.

Modul Materi Statika & Tumpuan

Klik pada setiap topik untuk Membuka / Menutup detail penjelasan materi

Untuk menjaga struktur konstruksi dalam kondisi stabil dan tidak bergerak, seluruh akumulasi gaya dan momen harus seimbang bernilai NOL:

ΣFx = 0 Jumlah Gaya Horizontal = 0
ΣFy = 0 Jumlah Gaya Vertikal = 0
ΣM = 0 Jumlah Momen Putar = 0

Tumpuan Sendi mampu menahan reaksi gaya dari dua arah (vertikal & horizontal), namun **tidak menahan momen (bebas berotasi)**.

Reaksi Horizontal (Rx): ADA (Rx ≠ 0)
Reaksi Vertikal (Ry): ADA (Ry ≠ 0)
Reaksi Momen (M): NOL (M = 0)
Aplikasi Lapangan: Engsel poros jembatan baja, pen sambungan portal kuda-kuda rangka baja.

Tumpuan Rol **HANYA menahan gaya vertikal (Ry ≠ 0)**. Tumpuan ini bebas bergeser secara horizontal untuk menampung pemuaian dan penyusutan struktur jembatan akibat perubahan suhu udara.

Reaksi Horizontal (Rx): TIDAK ADA / NOL (Rx = 0)
Reaksi Vertikal (Ry): ADA (Ry ≠ 0)
Reaksi Momen (M): NOL (M = 0)
Fungsi Utama: Memberikan kebebasan pergerakan horizontal agar jembatan tidak mengalami retak struktur saat memuai di siang hari.

Tumpuan Jepit adalah tumpuan kaku sempurna yang **menahan seluruh pergerakan vertikal, horizontal, dan mencegah rotasi/momen**.

Reaksi Horizontal (Rx): ADA (Rx ≠ 0)
Reaksi Vertikal (Ry): ADA (Ry ≠ 0)
Reaksi Momen (M): ADA (M ≠ 0)
Aplikasi Lapangan: Kanopi melayang (cantilever), tiang penerangan jalan tanam beton kaku, fondasi jembatan.
Tumpuan Horizontal (Rx) Vertikal (Ry) Momen (M) DoF Penerapan Lapangan
Sendi (Hinge) ADA (Rx ≠ 0) ADA (Ry ≠ 0) NOL (M = 0) 1 DoF Jembatan baja, pin truss
Rol (Roller) NOL / TIDAK ADA (Rx = 0) ADA (Ry ≠ 0) NOL (M = 0) 2 DoF Ujung tumpuan pemuaian jembatan
Jepit (Fixed) ADA (Rx ≠ 0) ADA (Ry ≠ 0) ADA (M ≠ 0) 0 DoF Kanopi melayang, fondasi tiang
